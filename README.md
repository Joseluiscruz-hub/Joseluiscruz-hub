## 🚀 Principales resultados

### 💸 Automatización y recuperación operativa en SAP

- Participación en la recuperación de un proceso de migración a SAP S/4HANA con más de **1 millón de partidas desalineadas**.
- Desarrollo de automatizaciones con **VBA y SAP Scripting** para conciliación, validación y compensación masiva de documentos.
- Contribución al desbloqueo de un cierre financiero relacionado con aproximadamente **$800 millones MXN en deuda flotante**.
- Análisis e ingeniería inversa de procesos operativos heredados en SAP ECC y S/4HANA.

### 📱 Digitalización de inventarios industriales

- Desarrollo de **Inventory Scanner Pro**, una aplicación Android para captura y trazabilidad de inventarios.
- Implementación con **Kotlin, Jetpack Compose, Room, Hilt, Firebase y arquitectura MVVM**.
- Integración con dispositivos industriales y lectores de códigos, incluyendo equipos Honeywell CK65.
- Reducción aproximada de **80% en los tiempos de captura**, de acuerdo con mediciones operativas internas.
- Manejo de sesiones, almacenes, ubicaciones, lotes, pallets, caducidades, movimientos y comparación contra información de referencia.

### 🦺 Plataforma de gestión de equipo de protección personal

- Desarrollo de una plataforma full-stack para administrar solicitudes, inventarios, entregas, aprobaciones y reposiciones de EPP.
- Implementación con **Next.js, React, TypeScript, Firebase, Firestore, Firebase Admin y Cloud Run**.
- Diseño de roles administrativos por planta, auditoría de movimientos, control de existencias y procesamiento transaccional.
- Incorporación de pruebas automatizadas, integración continua, App Check y controles de acceso server-side.

### 🔐 Investigación independiente de autenticación

- Investigación de un comportamiento anómalo de autenticación entre múltiples identidades en servicios de Microsoft.
- Documentación mediante videos, trazas de red Fiddler, capturas PCAPNG y análisis de tokens y sesiones.
- Presentación formal a Microsoft Security Response Center mediante los casos:
  - `MSRC 99279 / VULN-157991`
  - `MSRC 111068 / VULN-179344`
- Los reportes fueron revisados y cerrados sin confirmación del proveedor.
- La experiencia fortaleció mis conocimientos sobre MFA, Microsoft Entra ID, MSAL, OAuth/OIDC, tokens, sesiones y divulgación responsable.
